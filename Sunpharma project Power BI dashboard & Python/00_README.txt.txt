Project: Sun Pharma District-Level Market Attractiveness Index (MAI)

Submission Overview:
This folder contains the complete end-to-end data pipeline, machine learning model, and strategic outputs for the MAI project.

Recommended Reading Sequence:

Start with the 01_Sun_Pharma_MAI_Presentation. This is the core evaluation document detailing the methodology, variable selection, and business strategy.

Open 02_MAI_Interactive_Dashboard.pbix to view the interactive visualizations, heatmaps, and top 10 market rankings.

The 03_PCA_Model folder contains the Python script used for the Principal Component Analysis, along with the master dataset and the finalized 3-index output workbook.

The 04_Raw_Datasets folder contains the unmodified public health and demographic files used for initial data engineering.
